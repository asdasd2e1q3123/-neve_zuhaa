# День 13. ARP и DHCP

Представим ситуацию: ты подключил компьютер к Wi-Fi. Откуда он узнал свой IP-адрес? А как компьютер понимает, на какой MAC-адрес отправлять данные?

За это отвечают два важных сетевых протокола - **ARP и DHCP**

---
## 1. Что такое ARP?
**ARP (Address Resolution Protocol)** - протокол, который позволяет узнать MAC-адрес устройства по его IPv4-адресу в локальной сети
Помнишь, мы разбирали разницу между IP и MAC (этааа был 5 день, если мне память не изменяет) ?
IP-адрес используется для логической адресации, а MAC-адрес - для передачи кадров внутри локального сегмента сети.
Но возможна у вас возникнит вопрос, типа если компьютер знает IP другого устройства, как ему узнать его MAC?

**Для этого и нужен ARP**

## 2. Как работает ARP?

**Вот про ARP часто спрашивают на собесах**

Допустим, у нас есть два устройства:

- Компьютер A: `192.168.1.10`
- Компьютер B: `192.168.1.20`

Компьютер A хочет отправить данные компьютеру B, но не знает его MAC-адрес.

Происходит следующее:

1. Компьютер A отправляет ARP Request - широковещательный запрос в локальную сеть.
2. Все устройства получают этот запрос.
3. Устройство с IP `192.168.1.20` узнаёт свой адрес и отправляет ARP Reply с собственным MAC-адресом.
4. Компьютер A сохраняет полученную информацию в ARP-кэше и использует её для отправки кадров.

**Важно:** если компьютер обращается к устройству из другой сети, он обычно узнаёт MAC-адрес не удалённого сервера, а своего шлюза по умолчанию.

## 3. ARP-кэш

Чтобы не отправлять ARP-запрос каждый раз, устройства сохраняют найденные соответствия IP и MAC в специальной таблице - **ARP-кэше**

Записи в нём не хранятся бесконечно: динамические записи имеют срок жизни и со временем удаляются или обновляются. Конкретное время зависит от операционной системы и сетевой реализации.

Посмотреть ARP-кэш можно с помощью команд:

**Windows:**

```
arp -a
```

**Linux:**

```
ip neigh
```

В результате можно увидеть IP-адреса соседних устройств и соответствующие им MAC-адреса.

## 4. Безопасность: ARP Spoofing

У ARP есть одна важная особенность: протокол сам по себе не проверяет подлинность ARP-ответов.

Этим могут воспользоваться злоумышленники, отправляя ложные ARP-сообщения.

**ARP Spoofing (ARP Poisoning)** - атака, при которой в ARP-кэш устройства попадают ложные соответствия IP- и MAC-адресов. Это может позволить злоумышленнику перенаправлять сетевой трафик через своё устройство, **ну короче думаю знаете про атаку MITM** ну если нет, то поподробнее чуть попозже расскажу ну или вот ссылочка на сайте для ознакомления - https://habr.com/ru/articles/869898/

## 5. Что такое DHCP???

**DHCP (Dynamic Host Configuration Protocol)** - протокол, который автоматически выдаёт устройствам сетевые настройки

Когда ты подключаешься к Wi-Fi, тебе обычно не приходится вручную прописывать IP-адрес, маску подсети и шлюз, поэтому нужна говорить спасибо ему DHCP-серверу :))

Он может выдать устройству:

- IP-адрес;
- маску подсети;
- шлюз по умолчанию;
- адреса DNS-серверов;
- срок аренды IP-адреса (Lease Time).

## 6. Как работает DHCP?

Для первоначального получения настроек используется процесс DORA( если что не та которая с мейби бейби треки писала ) - четыре основных этапа:

**1. Discover (Обнаружение)**

Устройство ищет DHCP-сервер в сети и отправляет запрос

**2. Offer (Предложение)**

DHCP-сервер предлагает устройству свободный IP-адрес и другие настройки

**3. Request (Запрос)**

Устройство сообщает, что хочет использовать предложенный адрес

**4. Acknowledge (Подтверждение)**

Сервер подтверждает выдачу адреса и передаёт настройки

После этого устройство может использовать полученные параметры для работы в сети

## 7. Что такое аренда IP-адреса?

DHCP обычно выдаёт IP-адрес не навсегда, а на определённый срок. Это называется **Lease Time (время аренды)**.

До окончания аренды устройство пытается продлить её, отправляя DHCP Request серверу. Если сервер подтверждает продление с помощью DHCP ACK, устройство продолжает использовать тот же адрес.

Если устройство больше не нуждается в адресе, оно может отправить DHCP Release, добровольно освобождая аренду.

---

## 8. ARP и DHCP - в чём разница?

Подготовил вам табличку с сравнением ARP и DHCP

| ARP                       | DHCP                                   |
| ------------------------- | -------------------------------------- |
| Узнаёт MAC по IPv4        | Выдаёт сетевые настройки               |
| Работает в локальной сети | Используется для настройки подключения |
| Связывает IP и MAC        | Назначает IP, маску, шлюз и DNS        |

# День 12. Маршрутизация

В прошлых уроках мы разобрали IP-адреса, маски подсетей и научились определять, какие устройства находятся в одной сети

> **Но что происходит, если компьютер хочет отправить данные устройству из другой сети и как вообще пакет понимает, куда двигаться дальше?**

---

## 1. Что такое маршрутизация?

> **Маршрутизация - это процесс выбора пути, по которому IP-пакет передаётся от отправителя к получателю**

За выбор следующего узла отвечает маршрутизатор или другое устройство, выполняющее маршрутизацию

Например:

- Компьютер находится в сети `192.168.1.0/24`
- Сервер находится в сети `8.8.8.0/24`
- Эти устройства находятся в разных сетях

Чтобы отправить пакет серверу, компьютеру нужно передать его маршрутизатору

---

## 2. Шлюз по умолчанию

**Шлюз по умолчанию** - это IP-адрес маршрутизатора, которому компьютер отправляет пакеты, если адрес назначения находится за пределами локальной сети и для него нет более подходящего маршрута

Например, настройки компьютера:

- IP-адрес: `192.168.1.10`
- Маска: `255.255.255.0`
- Шлюз: `192.168.1.1`

Если компьютер обращается к `192.168.1.20`, адрес находится в той же подсети - пакет можно отправить напрямую

Если компьютер обращается к `8.8.8.8`, адрес находится в другой сети - пакет отправляется через шлюз `192.168.1.1`

---

## 3. Таблица маршрутизации

> **У каждого компьютера есть таблица маршрутизации - набор записей, определяющих, куда отправлять IP-пакеты**

Основные поля таблицы:

- **Сеть назначения** - сеть, в которую нужно доставить пакет
- **Префикс** - определяет размер сети назначения
- **Следующий узел** - IP-адрес следующего маршрутизатора, через который нужно отправить пакет
- **Интерфейс** - через какую сетевую карту отправить пакет

Вот сделал вам пример таблички:

| Сеть назначения | Следующий узел |
|---|---|
| `192.168.1.0/24` | Напрямую |
| `10.0.0.0/8` | `192.168.1.254` |
| `0.0.0.0/0` | `192.168.1.1` |

---

## Как выбирается маршрут?

Вы наверное могли подумать, типа что выбирается маршрут по самому короткой длине, ноооо устройство выбирает наиболее конкретный маршрут - тот, у которого совпадает больше всего старших битов адреса назначения, **да понимаю, слишком странно**

Например, для адреса `192.168.1.50` могут подходить маршруты:

- `192.168.0.0/16`
- `192.168.1.0/24`
- `0.0.0.0/0`

Будет выбран `192.168.1.0/24`, потому что `/24` - самый длинный подходящий префикс

---

## 4. Как посмотреть таблицу маршрутизации?

**Windows:**

```
route print
```

**Linux:**

```
ip route
```

В Linux также можно посмотреть, какой маршрут будет использован для конкретного адреса:

```
ip route get 8.8.8.8
```

# День 16. Порты и сетевые соединения

Представь проста, тебе нужно открыть сайт, ну или на крайняк уже зайти в доту, то твой компьютер должен не только определить, с кем нужно установить соединение, но и понять, какому приложению отдать данные

**Тут как раз появляются сетевые порты**

## Что такое порт?

Порт - это виртуальная точка, через которую начинаются и заканчиваются сетевые соединения. Порты реализованы программно и управляются операционной системой компьютера

Каждый порт связан с определённым процессом или службой. Благодаря портам компьютеры могут различать различные типы сетевого трафика. Например, электронная почта и веб-страницы используют разные порты, даже если данные поступают на один и тот же компьютер через одно интернет-соединение

(Объяснение что такое порт взял и перевел для вашего удобства вот от сюда - https://www.cloudflare.com/learning/network-layer/what-is-a-computer-port/)

Вообще порт представляет собой число от 0 до 65535

Ну я думаю, вы уже встречали например HTTP, HTTPS, DNS (даже в моих постах), но может не знали, что порт у:

- HTTP - 80
- HTTPS - 443
- DNS - 53

**!Но тут оговорка небольшая, что это стандартные порты, но никак не обязательные, то есть тот же HTTP может работать на 81!**

## Чем отличается IP-адрес от порта

Тут вообще легко все

**Можна представить для более легкого понимания, что айпи адрес - это адрес самого дома, а вот порт - это номер квартиры**

Например, адрес `192.168.1.10:443` означает что нужно передать данные пользователю с айпи `192.168.1.10` через 443 порт, а это у нас HTTPS

## Диапазоны портов

Вообще порты делят на 3 основные диапазоны:

1. `0-1023` - это системные, то есть ими пользуются распространенные сетевые службы, тут работают те же HTTP, HTTPS, DNS, ну короче все то, что вы уже слышали
2. `1024-49151` - зарегистрированные, ими уже пользуются различные сервисы и приложения, нуууу например 3306 - это MySQL, она помогает приложениям работать с базами данных, ну также часто встречается 8080 - он используется как альтернатива HTTP порту
3. `49152-65535` - динамические, они уже используются для временных соединений, они могут назначаться временно и могут меняться при каждом новом соединении

## Популярные порты

Подготовил для вас самые популярные порты, конечно их намного больше, но вот те которые встречаются чаще чем другие

| Порт | Протокол | Описание |
|---|---|---|
| 21 | FTP | используется для управления соединением |
| 22 | SSH | защищенное удаленное управление сервером, через ваш любими терминал :) |
| 23 | telnet | уже старый, заезжанный протокол для удаленного управления, ну тут самое главное, что ВСЕ ИДЕТ БЕЗ ШИФРОВАНИЯ, то есть вся передача полностью небезопасна |
| 25 | SMTP | отправка электронной почты между серверами |
| 53 | DNS | это преобразование доменных имен в айпи адреса, ну про это я расскажу завтра поподробнее |
| 67-68 | DHCP | уже про него рассказывал ранее, думаю вы помните, что он дает устройствам айпи адреса, но вот 67 используется сервером, а вот 68 - клиентом |
| 80 | HTTP | это обычный без какого шифрования веб трафик |
| 110 | POP3 | получение почты с сервера, ну можно сказать, что скачивание ее на устройство |
| 143 | IMAP | это получение почты с сервера, с синхронизацией на самом сервере |
| 443 | HTTPS | это уже защищенный через шифрование через TLS веб трафик |
| 445 | SMB | это общий доступ к файлам и принтерам в сети windows |
| 993 | IMAPS | защищенная версия IMAP |
| 3306 | MySQL | про нее уже рассказывал выше |
| 3389 | RDP | удаленный доступ к рабочему столу windows |
| 8080 | HTTP (альт.) | альтернатива HTTP, используется нуууу для например разработки сайта |
| 8443 | HTTPS (альт.) | альтернатива уже HTTPS, все по той же логике |
